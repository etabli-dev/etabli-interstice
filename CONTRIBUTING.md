# Contributing

This repository currently contains a design specification. Open an issue before implementing a substantial component so its behavior and acceptance criteria can be agreed.

Submit only original material or material whose license and provenance permit its inclusion. Contributions are offered under AGPL-3.0-only; contributors retain their copyright. There is no copyright assignment or automatic commercial relicensing grant.

Do not copy proprietary implementations, interfaces, documentation, artwork, private schemas or recorded user data. Use public standards, documented permitted APIs and synthetic fixtures. Record the origin, version and license of dependencies and reused material. Existing Établi components require the same provenance review as other dependencies.

Use the shared Établi design language with accessible contrast, keyboard operation, system/light/dark appearance and original layouts. Keep technical setup details out of daily task flows.

No credentials, deployment hostnames, real task exports, personal schedules or operational receipts belong in this public repository. Changes must identify what was tested and what remains unverified.
